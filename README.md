# MIRA Store

## تشغيل الصور (مرة وحدة)
الصور صارت بمجلد `images/` بدل ما تنحمّل من الإنترنت كل مرة.

1. افتح الترمنال داخل مجلد المشروع
2. شغّل: `python3 download-images.py`
3. بينزّل 45 صورة منتجات/أقسام + 6 صور عملاء (`images/avatars/`)

لو صورة مش موجودة محلياً، الموقع بيجيبها تلقائياً من Unsplash، فما بينكسر شي.

## تبديل صورة
حط صورتك داخل `images/` وغيّر اسمها بنفس الـ ID، أو بـ `script.js` حط مسار كامل مثل `img:'images/my-jacket.jpg'` للمنتج.
